# Security policy

## Supported versions

The latest Folder Managing Community 2.x release receives security and Windows
compatibility fixes. Older releases should be upgraded before reporting a
problem that may already be fixed.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability before a fix is
available.

Use **Security → Report a vulnerability** in this GitHub repository. Include:

- the affected version and Windows version;
- clear reproduction steps;
- the expected and actual result;
- the security impact;
- logs or a proof of concept with personal paths and data removed.

The report will be reviewed privately. A public advisory and corrected release
will be prepared when the issue is confirmed.
