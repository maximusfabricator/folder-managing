# Folder Managing Community Edition

Folder Managing 2.x is the free, open-source Community Edition. Its source and
published releases remain available under GPL-2.0-only.

## Maintenance

Community Edition is not an abandoned trial. It continues to receive:

- security fixes;
- compatibility fixes for supported Windows versions;
- bug fixes;
- reasonable improvements to the existing folder-coloring experience.

The core features already present in 2.x stay free, including folder colors,
tags, custom colors, Explorer integration, and manual settings import/export.

## Store and Pro editions

Folder Managing 3.x is developed separately for Microsoft Store distribution.
The Store app will include a free tier and an optional one-time Pro Lifetime upgrade
for convenience features such as synchronization, profiles, scheduled backups,
and automatic rules. Its source is private and its license is separate from
Community Edition; this does not change the GPL terms of any published 2.x release.

Contributions to this repository are accepted under GPL-2.0-only. They are not
automatically licensed for a closed-source edition and will not be copied into
one without separate permission from the contributor.

## Sponsorship

Any future sponsorship is voluntary. Sponsoring does not change the GPL license
or remove features from Community Edition.
