## Install

- Requires Windows 11 (x64).
- Download **FolderManaging-Setup-{VERSION}.exe** below and run it.
- Windows SmartScreen may warn you because the installer is not code-signed yet. Click **More info** → **Run anyway**.
- Confirm the administrator (UAC) prompt.
- Upgrading from an earlier version keeps your colors and settings.
- Version 2.2.0 and later offer new versions by themselves (Settings → Check for updates automatically). From 2.1.1
  or older, install this version once with the setup.

  `{SHA256}`

## Установка

- Нужна Windows 11 (x64).
- Скачайте **FolderManaging-Setup-{VERSION}.exe** ниже и запустите его.
- Windows SmartScreen может показать предупреждение, потому что установщик пока не подписан цифровой подписью. Нажмите **Подробнее** → **Выполнить в любом случае**.
- Подтвердите запрос администратора (UAC).
- При обновлении с предыдущей версии ваши цвета и настройки сохраняются.
- Версия 2.2.0 и новее сама предлагает обновления (Настройки → Автоматически проверять наличие обновлений). С версии
  2.1.1 и старше установите эту версию один раз вручную.
- SHA-256 файла `FolderManaging-Setup-{VERSION}.exe`:
  `{SHA256}`
